[pixelcharge-README.md](https://github.com/user-attachments/files/34780265/pixelcharge-README.md)# Pixelいたわり充電

Google Pixel に、Xperia の「いたわり充電（手動モード）」のような時間指定の充電制限を持たせるアプリです。
指定した時刻から充電を 80% で止め、満充電目標時刻の 50 分前に制限を解除します。

## できること

3 つのモードから選べます。

- **自動**：Pixel 標準のアダプティブ充電を有効にします
- **手動**：開始時刻から 80% 制限に切り替え、満充電目標時刻の 50 分前に制限を解除します（夜間の充電制限を想定）
- **常時**：常に 80% で充電を止めます

> 端末のバッテリー校正のため、まれに 100% まで充電されることがあります（Pixel 標準の仕様です）。

## 対応環境

- **Google Pixel 専用**です。他メーカーの端末では動作しません
- Google Pixel 6以降に対応
- Pixel 11,Pixel 9a,Pixel 7 Proで動作確認しています。他の Pixel 機種では未検証
- Android 16以降

## インストール

1. Releases から最新の APK をダウンロード
2. 端末の設定で「提供元不明アプリのインストール」を許可して APK をインストール

## 初回セットアップ（必須）

このアプリは Pixel の充電設定を切り替えるため、**PC から ADB コマンドを 1 回だけ実行する**必要があります（USB デバッグを使用。root は不要です）。

端末を PC に接続して、以下を実行してください。

```
adb shell pm grant jp.kr56.pixelcharge android.permission.WRITE_SECURE_SETTINGS
```

アプリ内（右上メニュー →「ADBコマンドを表示」）にも同じコマンドが表示されます。

あわせて以下を許可しておくと安定します。

- 設定 → アプリ → 特別なアプリアクセス →「アラームとリマインダー」で本アプリを許可
- 設定 → アプリ → 本アプリ → バッテリー →「制限なし」

## 注意事項

- 個人開発のアプリです。動作保証・サポートはありません
- ネットワーク権限はなく、データ収集は一切しません
- 充電制御は Pixel 標準の「充電の最適化」の設定を切り替える方式です。OS アップデート等で Pixel 側の仕様が変わると動作しなくなる可能性があります
- 時刻になっても切り替わらない場合は、バッテリー最適化の除外（「制限なし」）が効いているか確認してください

## アンインストール

通常のアプリと同じ手順でアンインストールできます。充電設定は Pixel の「充電の最適化」側に残るので、必要なら設定アプリから戻してください。
